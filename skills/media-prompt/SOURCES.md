## Corrections to the first draft

- **"The BFL page is now about FLUX 3 video."** It is about FLUX 3 Image. Video has its own pages, and FLUX 3 Video is API only.
- **"FLUX.2 ignores negative prompts."** BFL says so for [pro] and [max] only. For [dev], ComfyUI's template has no negative input. [klein] base runs real CFG and takes one.
- **"Users report LTX-2.5 follows prompts better with the enhancer off."** That is one Hugging Face [discussion](https://huggingface.co/Lightricks/LTX-2.5/discussions/36), with no reply from Lightricks. The skill relies on Lightricks' own guidance instead.
- **"81 frames at 16 fps" for Wan 2.2.** True for A14B only. TI2V-5B is 121 frames at 24 fps.
- **Krea 2 checkpoints grouped with FLUX.2.** Krea 2 is its own architecture, trained from scratch, with its own encoder and settings. It has its own file.
- **"One name, three models."** The name in question covers four checkpoints on three bases. Civitai's `baseModel` field confirmed which checkpoints moved from SDXL to Krea 2.
- **Test cases go in `evals.md`.** CONTRIBUTING puts them in `reviews/media-prompt/tasks.md`.
- **Wan's camera moves are in the guide's "cinematic aesthetic control" section.** They sit under dynamic control, and "camera pushes in" and "fixed camera" come from the image-to-video formula. "Wide-angle" is a shot size and tilt-shift a special-effect shot; the lens rows are long-focus and ultra-wide-angle fisheye only.
- **LTX's camera words end at "static frame".** The guide's list also has tilts upward, overhead view and wide establishing shot, and writes handheld as "handheld movement".
- **"FLUX 3 is not covered."** FLUX 3 Image Klein has open weights and runs in ComfyUI, so it has its own file. FLUX 3 Video and the full FLUX 3 Image are served through BFL's API.
- **"Klein Base runs at CFG 3.5."** BFL's Klein page, the ComfyUI card and the Base text-to-image template say 3.5. BFL's own code (`pipeline.py`) and README use 4. The file gives 3.5 and names the other.
- **"An edit caption is the whole scene with the edit folded in."** The ComfyUI card and the edit templates' note say so. BFL's edit system prompts, which write the captions the model was trained on, write an instruction about the change that ends with what stays. The file follows the system prompts.
