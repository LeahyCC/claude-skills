# diagramming

Draws clear ASCII and Unicode diagrams in terminal and markdown.

## What it covers

- Matching diagram type to content shape
- Three-tier glyph compatibility (ASCII, Unicode, geometry)
- Arithmetic alignment (no eyeballing)
- Fixed grid discipline
- Pattern library for common diagram types
- Pre-flight verification checklist

## When to use

- Explaining architecture or data flow
- Showing state transitions
- Comparing before/after structures
- Describing control flow with branches

## When not to use

- Simple one-line comparison → use a table
- UI mock-ups → use an Artifact
- Production diagrams with precise sizing → use Excalidraw or Mermaid
