## Structural comparison and limits

Anthropic skill-creator encourages task-based comparison and iteration. Vercel React Best Practices makes high-impact rules easy to find; Web Design Guidelines is a short entry pointing to maintained guidance. Adopt focused routing, priorities and selective incorrect/correct examples. Do not import their broad activation scope or treat their rules as Next API authority. No external skill prose or code is copied; original repo MIT license remains intact.

This repo has markdown, a command and JSON catalogs, with no installer or runtime code implementing metadata triggers. The inspected Vercel skills discovery source reads name/description and passes metadata through; this does not establish that every third-party host ignores metadata. Retain the pilot's fields for external compatibility and explain their non-effect in Claude Code. CONTRIBUTING and other skills still make trigger claims: flag for a separate repo-wide change rather than extending this pilot.

React-performance duplicates component/assets guidance; SEO duplicates metadata. Keep ownership boundaries and optional links; no sibling edits. Both plugin manifests describe the pilot and repeat trigger patterns. Their display-only verified claims should point to scoped source records; schema repair for the whole plugin is separate work.
